# Projeto de Controle de Estoque

Projeto desenvolvido pela equipe de Estoque ao longo das atividades da disciplina de programação.

O projeto acompanha a evolução das soluções desenvolvidas durante as etapas da disciplina, aplicando os conceitos estudados ao domínio de controle de estoque.

## Domínio

A equipe trabalha com o domínio de **Estoque**.

Entre os conceitos relacionados ao domínio estão:

* entrada de produtos;
* saída de produtos;
* ajuste de inventário;
* controle da quantidade disponível;
* estoque mínimo;
* alerta para produtos abaixo do estoque mínimo.

## Estrutura

O repositório é organizado conforme a evolução das atividades do projeto:

```text
aula02-paradigmas/
    Refatoração funcional e testes

aula03/
    Práticas de Python aplicadas ao desenvolvimento

aula04/
    Laços, funções, módulos e testes

...
```

As pastas representam etapas de desenvolvimento e aprendizagem do projeto. A implementação do domínio evolui progressivamente conforme os conceitos da disciplina são incorporados.
